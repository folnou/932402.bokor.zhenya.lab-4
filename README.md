# Лабораторная работа №4
**Вариант:** 6  
**Тема:** «Любитель кино и сериалов» (длительность фильмов, основы JavaScript)  
**Цветовая гамма:** Чёрно-золотая 

## Выполненные требования

### 1. Ввод и вывод данных
- **`prompt`**: Реализован запрос имени пользователя с валидацией (проверка на `null` при отмене и на пустую строку после `trim()`).
- **`alert`**: Используется для приветствия пользователя и вывода итоговой сводки о длительности просмотра.
- **`console.log`**: Применяется для отладки и вывода структурированной статистики (исходный массив, результаты фильтрации, подсчеты).

### 2. Условные конструкции и циклы
- Использованы циклы `for` и `for...of` для обхода массива длительностей.
- Реализованы условные операторы `if` для:
  - Фильтрации фильмов по заданным порогам (> 120 мин, ≤ 40 мин).
  - Проверки дополнительного условия: если максимальная длительность ≥ 180 минут, выводится сообщение про «театральный спектакль».

### 3. Функциональность (Функции)
Реализованы отдельные переиспользуемые функции:
- `findMax(arr)`: Поиск максимального элемента в массиве с проверкой на пустоту.
- `filterLongerThan(arr, minDuration)`: Возвращает новый массив, отфильтрованный по условию.
- `sumArray(arr)`: Подсчет суммы элементов массива.
- `countShortFilms(arr, maxDuration)`: Комплексная функция, возвращающая объект `{ count, total }` с количеством и суммарной длительностью короткометражек.


## Запуск
1. Откройте файл `lab4.html` в любом современном браузере.
2. При загрузке страницы (или по триггеру) скрипт запросит имя и выведет приветствие.
3. Откройте **Инструменты разработчика** (F12) → вкладка **Console**, чтобы увидеть детальную статистику обработки массива и проверочные сообщения.

## Проверка
Код проверен на корректность логики:
- Фильтрация и суммирование работают независимо друг от друга.
- Обработка краевых случаев (например, отмена ввода в `prompt`) не вызывает ошибок и возвращает значение по умолчанию ("Гость").
